# Sulfurcave_ferro_virus
Code and analysis pipelines for the multi-omic characterization of a gas-driven, ultra-acidic viral-microbe consortium.

# Analysis of a Gas-Driven Acidophilic Biofilm Consortium
This repository contains the integrated metagenomic, metaproteomic, and viromic pipelines used to characterize the extremely acidic (pH ~1) biofilm of Movile Cave.Our analysis focuses on the metabolic interdependence between the sulfur-oxidizing archaeon Ferroplasma and the methanotroph Mycobacterium, as well as the specialized structural adaptations of the virosphere sustaining this gas-powered food web.

# Key Features:
- **Genome-Resolved Metagenomics**: Recovery and pangenomic analysis of high-proton environment MAGs.
- **Viromics & Host-Linkage**: Identification of novel viral contigs and high-fidelity CRISPR spacer-protospacer matching.
- **Structural Proteomics**: Physicochemical analysis of viral structural proteins (pI, GRAVY, and aromaticity shifts).
- **Metaproteomics Integration**: Functional profiling of the biofilm’s anabolic core.
